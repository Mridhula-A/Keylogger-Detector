\# KEYGUARD SECURITY CENTER



A Windows-based Keylogger Detection and Security Analysis Dashboard built using Python and Flask.



\## Features



\- Process Scanner

\- Keyboard API Scanner

\- Windows Startup Scanner

\- Registry Security Analyzer

\- Suspicious File Scanner

\- Real-time Dashboard Statistics

\- SQLite Scan History

\- Scan Reports and CSV Export

\- Scan History Search and Filters

\- Delete and Clear Scan History



\## Technologies Used



\- Python

\- Flask

\- HTML5

\- CSS3

\- JavaScript

\- SQLite

\- psutil

\- pefile



\## Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/YOUR-USERNAME/Keylogger-Detector.git

&#x20;  ```



2\. Open the project folder:



&#x20;  ```bash

&#x20;  cd Keylogger-Detector

&#x20;  ```



3\. Create a virtual environment:



&#x20;  ```bash

&#x20;  python -m venv venv

&#x20;  ```



4\. Activate it on Windows PowerShell:



&#x20;  ```powershell

&#x20;  .\\venv\\Scripts\\Activate.ps1

&#x20;  ```



5\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



\## Run the Application



```bash

python app.py

```



Open your browser and visit:



`http://127.0.0.1:5000`



\## Disclaimer



This project is developed for educational and defensive cybersecurity purposes. Detection results are heuristic indicators and do not guarantee that a file or process is malicious or safe.
